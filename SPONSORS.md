# Sponsors

The Panhandler has no sponsors yet. It runs on a second-hand Raspberry Pi 3B and spare time.

To support the project:

- Star the repo, and report bugs or hostile-network behaviour you've seen.
- Contribute code or docs (see [CONTRIBUTING.md](CONTRIBUTING.md)).
- Ask [@lowcache](https://github.com/lowcache) about funding. Hardware for v2, such as a USB Wi-Fi
  dongle with monitor mode or an LTE modem for lost mode, is the most direct help.

Sponsors will be listed here.
